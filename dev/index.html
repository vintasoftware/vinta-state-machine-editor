<state-machine-editor>

Order fulfilment flow — everything below is the plain custom element.

How to use it
  • Move a state: drag its header.
  • Colour: press the round swatch in a state's header and pick from neutral, info, success, warning, danger or muted. The bar across the top of the card takes that colour.
  • Initial / final: toggle ▶ Initial and ◉ Final at the bottom of a state card. A state can be both, and a machine can have several of each.
  • Reposition a transition: drag its card — the line bends to follow. Drop it back on the line to let the editor place it again.
  • Connect two states: drag the round → handle onto another state (drop it on the same state for a self transition).
  • Rename: tap the ✎ button (or double-click the name), then ✓ to save or ✕ to discard. With something selected, F2 works too.
  • Side effects: a chip shows the first name, with a small count badge on its left edge when the list holds more than one. Click any chip to open the dialog — add from the catalog, remove, and reorder by dragging ⠿ (or Alt + ↑/↓).
  • Parameters: press { } on a side effect to edit its JSON, either as a nested form or in a CodeMirror editor with highlighting, bracket matching and undo. Chips showing { } have at least one side effect with parameters.
  • Pan: drag the background, scroll, or move two fingers together. Zoom: pinch on a trackpad or touchscreen, toolbar buttons, or Ctrl/⌘ + scroll.
  • Delete: select a state/transition and press Delete.
  • Copy / paste: select a state or transition, then Copy / Paste in the toolbar, or Ctrl/⌘ + C and Ctrl/⌘ + V. The copy carries the side effects, colour and attributes across under ids of its own; initial/final roles stay behind.
  • Theme: the toolbar's ☀ / ☾ switches the canvas between dark and light. A host picks the one it opens in with the theme attribute — dark when it says nothing — and hears about every switch through state-machine-theme-change. The picker above and this page's own colours are wired to exactly that.
  • Icons: the picker above swaps every glyph the canvas draws through the icons property — plain strings for the emoji set, <svg> nodes built per button for the other. Nothing is rebuilt: each icon is redrawn where it stands, dialogs included. A partial set replaces only what it names, and the glyphs written into these hints are the defaults.
  • Undo / redo: the toolbar's ↶ / ↷, or Ctrl/⌘ + Z and Ctrl/⌘ + Shift + Z. A whole drag, and a whole properties save, each count as one step.
  • Decisions: several edges leaving one state under one action are drawn as a single card, tried top to bottom — see ⚡ import.finish below Processing items. Drag a row's ⠿ (or Alt + ↑/↓) to change which is tried first, and click a row to edit that edge in place. The unguarded row is the else, and anything behind it is struck through: nothing can follow an edge that always matches.
  • Waiting: ⑂ Waiting on a state card says it fans work out to child records and waits for the batch. The band above the hook lanes names what it fans out to, the action that closes the wait and how long it is given; Fans out to is a link, and the page logs the state-machine-fan-out event rather than navigating.
  • Counts as: a state that reports into its parent's batch shows it as one line of that band, from state.data.counts_as. Toggle ◉ Final on Paid to watch the control drop its leave half — a final state can never be left, so that hook could never fire.
  • Warnings: advisory stripes appear on the card that has the problem — a decision with no fallback, a wait nothing closes, a terminal state with a way out. Paid carries one on purpose, since refund leaves it. They never block an edit.
